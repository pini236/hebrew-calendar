# לוח יהודי: יומן עברי־לועזי וזמני היום, בלי פרסומות

ב־Google Play ובאנדרואיד השם הוא **לוח יהודי**. ב־App Store ובאייפון השם הוא **לוח עברי**.

אפליקציית לוח שנה עברי ולועזי, עם זמני היום, חגים, לימוד יומי ואירועים אישיים.
היא בנויה כ־PWA: נפתחת בדפדפן, אפשר להתקין אותה למסך הבית בטלפון, והיא עובדת גם בלי אינטרנט.
כל החישובים נעשים במכשיר עצמו. אין פרסומות ואין מעקב.

## דיוק

- **זמני היום**: [KosherJava](https://github.com/BehindTheMath/KosherZmanim) (kosher-zmanim), המנוע שרוב אפליקציות הזמנים בנויות עליו. חצות היום היא חצות אסטרונומית (מעבר השמש בקו האורך).
- **לוח השנה**: תאריכים, חגים, פרשות, הדלקת נרות והבדלה מחושבים ב־[Hebcal](https://github.com/hebcal/hebcal-es6).
- **מיקום הערים**: קואורדינטות ממאגר GeoNames. אזור הזמן של כל מקום נקבע לפי הקואורדינטות שלו (ראו "חיפוש מיקום" למטה).
- **בדיקה צולבת**: `npm run verify` משווה כל זמן, ב־51 ערים ובכל יום בשנה, מול הספרייה השנייה. בנוסף הוא בודק תאריכים עבריים בין 1950 ל־2100 וימים טובים בארץ ובחו״ל. בתוצאה האחרונה ההפרש הגדול ביותר היה שנייה אחת, ולא נמצאה אף אי־התאמה.
- **הבדל ידוע**: במצב "חישוב לפי גובה", זמני מגן אברהם מחושבים מזריחה לפי הגובה (KosherJava). Hebcal מחשב אותם מזריחה בגובה פני הים, ולכן במצב הזה יש ביניהם הפרש של כדקתיים. ברירת המחדל היא גובה פני הים, ושם שתי הספריות זהות.

## מה יש בפנים

- **שמיים חיים**: הכרטיס של היום משנה צבע לפי השעה האמיתית ביחס לזריחה ולשקיעה במקום שבחרתם. השמש זזה על הקשת, ובלילה רואים כוכבים וירח במופע הנכון לפי התאריך העברי. אחרי השקיעה מופיעה תזכורת שהתאריך העברי כבר התחלף.
- **לוח חודשי** בשני מצבים: חודש לועזי או חודש עברי. בכל יום רואים את התאריך השני, חגים, ראשי חודשים, פרשת השבוע ומועדים. מחליקים ימינה ושמאלה כדי לעבור בין חודשים.
- **זמני היום המלאים**: עלות השחר, משיכיר, הנץ, סוף זמן ק״ש ותפילה (מג״א והגר״א), חצות, מנחה גדולה וקטנה, פלג המנחה, שקיעה, צאת הכוכבים, ר״ת וחצות הלילה. הזמן הבא מסומן עם ספירה לאחור, וזמנים שעברו מעומעמים. בערב פסח נוספים סוף זמן אכילת חמץ וביעורו, ובימי צום נוספות שעות תחילת הצום וסיומו.
- **התראה בכל יום שישי**: בבוקר מגיעה התראה עם שעת כניסת השבת ושעת היציאה, למשל "שבת פרשת ויצא · כניסה 15:57 · יציאה 17:16". האפליקציה יוצרת קובץ יומן (.ics) לשנה קדימה ומוסיפה אותו ליומן של הטלפון, ולכן ההתראות מגיעות גם כשהאפליקציה סגורה. שעת ההתראה ניתנת לשינוי.
- **התראות לכל זמן** (באפליקציה לאנדרואיד ולאייפון): בוחרים זמנים, כמו סוף זמן ק״ש (גר״א או מג״א), סוף זמן תפילה, שקיעה, צאת הכוכבים או חצות, וכמה דקות לפני כל אחד (0, 5, 10, 15 או 30). ההתראה נראית כך: "סוף זמן ק״ש (גר״א) בעוד 15 דק׳ · 08:44 · ירושלים". יש גם תזכורת להדלקת נרות (ברירת מחדל 30 דק׳ לפני) בערב שבת ובערב חג, התראה בצאת השבת והחג, ובתחילת הצום ובסיומו. צום שמתחיל בעלות השחר מוזכר בערב שלפניו ב־21:00, ולא באמצע הלילה. ההתראות מחושבות מחדש בכל פתיחה של האפליקציה ובכל החלפת מיקום או הגדרה. אייפון שומר עד 64 התראות ממתינות לכל אפליקציה, ולכן יש להן תקציב: תזכורות לאירועים, שבת וחג קודמים, וזמני היום ממלאים את השאר בימים שלמים (עד 10 ימים; פחות ימים כשבוחרים הרבה זמנים). באתר עצמו דפדפן לא יכול לשלוח התראות בזמן, ולכן המסך רק מסביר ומראה דוגמה.
- **שבת וחג קרובים**: הדלקת נרות ויציאה, לפי מנהג העיר (ירושלים 40 דק׳, חיפה 30 וכו׳). אפשר לשנות.
- **בתפילה היום**: הלל, תחנון, יעלה ויבוא, על הניסים, טל ומטר, וספירת העומר.
- **לימוד יומי**: דף יומי, משנה יומית, נ״ך יומי, רמב״ם, חפץ חיים ותהילים.
- **קפיצה בזמן**: רשימת חגים ומועדים לשנה הקרובה עם חיפוש. אפשר גם לבחור תאריך עברי (יום, חודש ושנה) או לועזי, או לזוז X ימים, שבועות, חודשים או שנים קדימה או אחורה. לפני הקפיצה מוצגת תצוגה מקדימה של שני התאריכים.
- **האירועים שלי**: ימי הולדת, יארצייטים ופגישות. אירוע יכול לחזור כל שנה לפי התאריך העברי (כולל טיפול באדר א׳/ב׳) או לפי הלועזי. אפשר להזין את התאריך המקורי כתאריך לועזי או כתאריך עברי (יום, חודש ושנה), ולסמן "אחרי השקיעה": אירוע שהיה בערב חל כבר בתאריך העברי של למחרת, וכך הוא חוזר בכל שנה. לכל אירוע אפשר לבחור תזכורת: ביום עצמו (בשעה שבוחרים, ברירת מחדל 08:00), בערב שלפני (20:00) או שבוע לפני. האירועים נשמרים במכשיר, ואפשר לייצא גיבוי ולייבא אותו.
- **חיפוש מיקום בכל העולם, גם בלי אינטרנט**: כ־25,000 מקומות. בארץ כל הישובים שב־GeoNames, ובחו״ל כל עיר עם 15,000 תושבים ומעלה. מחפשים בעברית (הערים המוכרות, או שם של מדינה, למשל "צרפת") או באנגלית, גם בלי ניקוד ואותיות מיוחדות (Montreal, Tromso). אפשר לצמצם לפי מדינה או מחוז: "Springfield, Illinois". רשימת המקומות נטענת רק כשפותחים את מסך המיקום, כדי שפתיחת האפליקציה תישאר מהירה. 5 המקומות האחרונים שמורים, ואפשר לאתר מיקום לפי GPS. בכ־50 הערים המוכרות נשמרים השם העברי, הגובה ומנהג הדלקת הנרות (ירושלים 40 דק׳, חיפה 30 וכו׳). מקום חדש מחושב בגובה פני הים, עם 20 דק׳ בארץ ו־18 בחו״ל.
- **גודל טקסט וניגודיות**: רגיל, גדול או גדול מאוד. "רגיל" מתאים את עצמו לגודל הגופן שבהגדרות הטלפון או הדפדפן. מצב ניגודיות גבוהה מכהה את הטקסט המשני ואת הקווים, בבהיר ובכהה.
- מצב כהה ובהיר, וקיצורי מקלדת במחשב: ← → לימים, ↑ ↓ לשבועות, PgUp/PgDn לחודשים, T להיום, G לקפיצה.

## הרצה מקומית

```bash
npm install
npm run dev        # שרת פיתוח
npm run build      # בנייה ל-dist (PWA)
npm run verify     # בדיקת דיוק מול ספרייה שנייה
npm test           # בדיקות לתכנון ההתראות (כולל מגבלת 64 ההתראות) ולחיפוש המיקום
```

### חיפוש מיקום: איך נבנה קובץ המקומות

הקובץ `src/data/places.txt` (כ־900KB, כ־440KB בדחיסה) נבנה בסקריפט `scripts/build-places.mjs` ונשמר במאגר. לכן הבנייה הרגילה לא צריכה שום הורדה.
כדי לבנות אותו מחדש:

```bash
npm i --no-save cities.json@1.1.66 all-the-cities@3.1.0 geo-tz@8.1.11
npm run places
```

- **שמות וקואורדינטות**: החבילה `cities.json`, שהיא מאגר GeoNames. ממנה נלקחו גם הקואורדינטות של הערים ב־`src/lib/cities.ts`.
- **מספר תושבים**: ב־`cities.json` אין מספר תושבים, ולכן הוא נלקח מ־`all-the-cities`, שהיא גרסה אחרת של אותו מאגר. ההתאמה נעשית לפי מדינה, שם וקואורדינטות.
- **אזור זמן**: גם הוא חסר ב־`cities.json`. הוא נקבע לפי הקואורדינטות בעזרת `geo-tz`, שבודקת באיזה פוליגון של אזור זמן הנקודה נמצאת. כך אין צורך לנחש אזור זמן לפי מדינה, וגם ערים במדינות עם כמה אזורי זמן מקבלות את האזור הנכון. אם לא נמצא אזור (נקודה שנמצאת ממש על קו החוף), נבחר האזור הנפוץ באותה מדינה. בזמן ריצה, אם במכשיר חסר אזור זמן מסוים, משתמשים באזור הזמן של המכשיר.
- **ארץ ישראל**: כל הישובים בישראל וביהודה, שומרון ועזה נכללים, כולם לפי שעון ישראל (Asia/Jerusalem) וכולם לפי מנהג ארץ ישראל (יום טוב אחד).

## אפליקציות לאנדרואיד ולאייפון

אותו קוד בדיוק נארז כאפליקציה רגילה לשתי החנויות בעזרת [Capacitor](https://capacitorjs.com), בתיקיות `android/` ו־`ios/`.
באפליקציה המותקנת כל ההתראות (יום שישי, זמני היום, הדלקת נרות, צאת שבת, צומות ותזכורות לאירועים) הן התראות אמיתיות של הטלפון, בלי לעבור דרך היומן, והן מתעדכנות בכל פתיחה. באנדרואיד הן נקבעות כהתראות "לא מדויקות" (inexact), כדי שלא תידרש הרשאת השעון המעורר, ולכן התראה עשויה להגיע באיחור של כמה דקות במצב חיסכון בסוללה.

```bash
npm run cap:sync   # בנייה והעתקה לפרויקטים של אנדרואיד ואייפון
```

הבנייה וההעלאה לחנויות רצות ב־GitHub Actions. ההוראות המלאות, כולל הסודות שצריך להגדיר, נמצאות ב־[PUBLISHING.md](PUBLISHING.md).

## פרסום ב-GitHub Pages

בכל push לענף הראשי של המאגר רץ ה-workflow שב-`.github/workflows/deploy.yml`.
כדי להפעיל אותו פעם ראשונה: Settings → Pages → Source: **GitHub Actions**.
אחרי הפרסום פותחים את הכתובת בטלפון ובוחרים "הוספה למסך הבית".

> הערה: הזמנים מחושבים לפי נוסחאות אסטרונומיות מקובלות. לפסקי הלכה מדויקים כדאי להשוות ללוח המקומי שאתם נוהגים לפיו.
